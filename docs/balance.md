# 平衡说明（2026-11-17 调整）

## 目标

| 难度 | 目标 |
|---|---|
| 简单 | 不放技能也能通关 |
| 普通 | 正常游玩不卡关 |
| 困难 | 需要把鬼灵练满、会用技能 |
| 噩梦 | 练满后仍有硬仗，需要站位、合击与构筑 |
| 禁忌 | 很难但可通 |

## 测量方法

`node tools/balance_sim.cjs [种子数] [难度]`：一个「合格玩家」机器人走真实路线打完整 46 幕（剧情 → 主战 → 岔路四选一轮换 → 篝火），
会显形、破鬼障、放技能和卡牌、买法器，但不会精细站位、不用羁绊合击、契约一律选素契。每场最多重试 3 次，仍输记为「卡关」后强行通过继续统计。

- `SIM_OVER=0` 只练到本幕推荐等级（随便玩的玩家）；`SIM_OVER=1` 练到等级上限（认真玩的玩家）。
- `SIM_FORK=mix|explore|trial|shop|omen` 岔路选法；`SIM_SET='{"hard":{"atk":3}}'` 临时改难度参数；`SIM_VERBOSE=2` 打印每场失败时的敌我数值；`SIM_RANKS=1` 打印经验缺口。

## 结果（2 个种子，每个种子 57 场）

| 难度 | 随推荐练：首次胜率 / 卡关场数 | 练满：首次胜率 / 卡关场数 |
|---|---|---|
| 简单 | 100% / 0 | 100% / 0 |
| 普通 | 92% / 2+1 | 98% / 0 |
| 困难 | 70% / 11+10 | 96% / 0+2 |
| 噩梦 | 约 40% / 成片 | 75% / 3+8 |
| 禁忌 | 约 35% / 成片 | 54% / 16+15 |

调整前（同一机器人）：普通 79%、5+2 场卡关；困难 62%；噩梦 30%；禁忌 11%，且经验不设上限时困难以下可以靠越级碾压（100%）。

## 改了什么

1. **等级上限**：主线里鬼灵最多比当前幕的推荐等级高 1 级（`rankCap()`）。原来中期一场战斗的经验够连升好几级，等级压制可以无视难度。
2. **一键修行**（`trainTeam`）优先练出战队伍里最强的 4 只，不再把经验摊给替补（原来会导致第 44 幕等处主力升不上去）。
3. **按等级段拉平**（`FLAT_A` / `FLAT_H`，难度参数 `flat`，只有困难以上使用）：原始数值里敌人相对鬼灵的强度各等级段相差数倍，
   统一倍率下 13–25 幕成墙、26 幕后不痛。现在每个等级段的「首领攻击/鬼灵生命」「首领生命/鬼灵攻击」被拉到同一水平。
4. **渐进幕数**（`easeActs`）：难度倍率从第 2 幕渐进到满强度的幕数，困难、噩梦、禁忌都是 10（原来统一 8；首领额外技能数仍按 8 幕渐进）。
5. **倍率**：普通攻击 2.63 → 2.4；困难 生命 3.67 → 3.4、攻击 3.31 → 2.9；噩梦 5.69/4.74 → 4/3.2；禁忌 10/7.6 → 4.4/3.4
   （禁忌另有等级压制 +1、两层鬼障、不死之躯，实际强度仍高于噩梦）。
6. **经济**：鬼市价格与异兆里的冥钱数额随幕数上涨（第 46 幕 ×3.7）；法器每多一件再贵两成；精英战的法器按幕数有上限
   （2 + 幕数/3.5），到上限改给 3 倍冥钱。原来通关时剩 7000–8000 冥钱、前十几幕就能把 15 件法器拿全。
7. 预留 `biteFloor`（敌方空路直击下限）参数，目前各难度为 0。

`node tests/difficulty_test.cjs 1`（旧的两个机器人，每幕喂满经验）：不放技能 简单 100% / 普通 39% / 困难 13% / 噩梦 2% / 禁忌 2%；
会放技能 100% / 98% / 48% / 39% / 17%。

## 已知局限

- 机器人不会站位和合击，噩梦/禁忌的「卡关」对真人不一定成立；没有真人数据。
- 86 张卡、15 件法器、契约条款、开局馈赠之间的相对强度没有逐项测量。
- 无尽模式与每日挑战沿用同一套难度参数，没有单独调整。


## 独立审查后的改动与复测（2026-11-18）

审查报告（`review.md`）指出的平衡问题和处理：

- **难度倒挂**：`tuned()` 的拉平表会把高难度终幕（及 38–40 幕）的倍率压到普通难度之下。现在加了下限：困难以上任何一幕的生命/攻击倍率不低于普通同幕的 1.075 / 1.12 / 1.15 倍。
- **鬼障缓入**：噩梦/禁忌的 `wardBase` 以前从第 2 幕起就是 0（普攻完全无效），现在和其他数值一样在前 10 幕内缓入。
- **异兆代价**：「失去生命 / 命灯」以前紧接着就能被免费的全队恢复抹掉。现在改成「下一场战斗开局先失去 X%」（`state.xWound` / `state.xDim`，在战斗开局结算）；以恢复为收益的选项换成香火或冥钱；鬼市「一碗热汤」换成「一炷好香」。
- **归巢**：改为只减下一次显形的费用（以前是整场永久减费）。
- **首领技能**：轮到已用满次数的技能时顺延到下一个可用技能，不再空过施法回合。
- **鬼市**：不再卖删牌（「鬼灵与卡牌」里本来就能免费删，现在牌组至少保留 8 张），改卖经验「抄一卷经」，给后期冥钱一个去处。

复测（`SIM_OVER=1 node tools/balance_sim.cjs 2 <难度>`，2 个种子；噩梦以上机器人避开带代价的异兆选项）：

| 难度 | 培养 | 首次胜率 | 重试后仍卡住 | 卡住的幕 |
|---|---|---|---|---|
| 普通 | 不超练 | 92% | 2+1 | 9、10、18 |
| 普通 | 练满 | 98% | 0 | — |
| 困难 | 练满 | 95% | 0+2 | 2、3 |
| 噩梦 | 练满 | 71% | 4+5 | 11、13–15、20、26、34 |
| 禁忌 | 练满 | 59% | 20+14 | 11–29 的大部分、46 |

与改动前（98% / 96% / 75% / 54–62%）基本一致，目标「普通不卡关、困难以上需要构筑、禁忌很难但可通」仍然成立。已知未处理：困难第 2、3 幕对朴素机器人偏硬；每日挑战第 1 波（三词缀）机器人必败；上香仍是每场战斗前点一下的重复操作。
