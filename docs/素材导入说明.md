# 素材导入说明

> 本文件由 `node tools/asset_doc.cjs` 生成，不要手改；空位总表在 `src/app/core/asset-slots.js` 和 `src/app/fx/video-map.js`。

游戏里所有需要外部制作的素材都留好了空位。**把文件按下表的文件名放进对应文件夹，刷新页面即生效，不需要改代码。** 游戏内「设置 → 素材清单」可以随时查看哪些已放入、哪些还是空位。

## 总览

| 类别 | 文件夹 | 文件名 | 格式 | 进度 | 缺失时的表现 |
|---|---|---|---|---|---|
| 技能视频 | `assets/video/` | `<鬼灵id>_<序号>`，升级版加 `p` | mp4 / webm，横幅 16:9，3–6 秒 | 0 / 73 | 纯黑画面 + 技能名（设置里可改回程序演出） |
| 音乐 | `assets/music/` | 见音乐表 | mp3 / wav / ogg / m4a | 0 / 22 | 用“缺失时代替”一栏的曲子；都没有则无音乐 |
| 卡面 | `assets/cards/` | `<鬼灵id>` | png / webp / jpg，竖幅 2:3 | 0 / 24 | 印章卡面 |
| 立绘 | `assets/views/` | `<鬼灵id>_front` / `_side` / `_back` | png / webp，**透明底**抠图，高约 720 像素 | 0 / 66 | 无相灵体（一团人形雾气） |

提示词在四份提示词文档里：`01_立绘`、`02_卡面`、`03_音乐`、`04_技能视频`，编号和文件名与下表一致。必须通过 `启动游戏.cmd`（或 exe）运行，直接双击 html 读不到文件夹。

## 一、技能视频

- 触发：该鬼灵施放该技能时播放，播完（或点击 / 空格跳过）后在牌桌上结算。被动技能每场战斗只在第一次触发时播。
- 画幅：「全屏」的视频铺满屏幕；「中间横带」的视频只显示画面中间约 60% 高度的一条，主体请放在画面中部。
- 升级技能（如「鬼火+」）默认用基础版视频；想区分就再放一个 `<文件名>p.mp4`（两个加号用 `pp`）。
- 视频自带声音会播放，音量跟随「音效音量」。演出模式为「仅牌桌」时不播任何视频。
