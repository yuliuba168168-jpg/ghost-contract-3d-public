# 02 卡面提示词（全部 22 名鬼灵，共 24 张）

新卡面我打算改成**整张满版插画**（现在是上半张拱形小窗），名字、阶位、数值压在画面下方的暗部上。所以构图有固定要求，见「通用段」。

## 使用方法

1. **每张都上传该角色自己的三视图作为「角色参考图」**，外形、发型、服饰以三视图为准；提示词里只写姿势、场景、光影和元素。新做的 8 名先用文档 01 生成三视图，再拿来当参考。
2. 「通用段」原样放最前面，再接该角色的「画面段」。
3. 画幅：竖幅 **2:3**，建议 1024×1536 或更高。
4. 交付文件命名：`<id>.png`，如 `xuan.png`；童童三张分别是 `tong.png`、`tong_evil.png`、`tong_valkyrie.png`。
5. 全套请尽量用同一个模型、同一套参数生成，保证 24 张放在一起是一套牌。

> 14 名已有鬼灵的实际长相我还没看到图，下面没有描述她们的外貌，全部交给参考图决定。个别身份（如青竹 = 寂照庵主）是我从小说里对出来的，如有出入请告诉我。

## 通用段（每条都加）

```
竖幅 2:3 卡牌插画，单人，角色外形、发型、服饰严格依照参考图。半写实厚涂的东方暗黑幻想风格：人物保留二次元的精致五官，材质和光影按写实绘制，有体积光和明确的主光源。整套色彩限定在靛蓝、朱砂红、骨白、烛光暖金四个主色里，暗部压得很深，只让一两处发光体成为最亮点。构图：角色的脸和上半身位于画面上方三分之二并居中，视线看向观者或略偏；画面下方三分之一逐渐沉入暗部或雾气，细节很少，留给卡牌文字；四周留出少量边距，重要内容不要贴边。无文字、无边框、无水印、无 logo。气质幽冥诡异、克制，不血腥、不暴露。高清，细节丰富。
```

反向提示词（工具支持时填写）：

```
文字, 水印, 签名, 卡牌边框, UI, 多人, 肢体残缺, 多余手指, 画面过亮, 高饱和糖果色, Q版, 3D渲染, 照片, 血腥, 裸露
```

类型光色约定（已写进各条，供你微调时参考）：善灵 = 冷月白光；恶灵 = 朱砂红光；规律鬼 = 青绿或冰蓝的几何光；禁忌 = 抽掉颜色的灰白；邪神 = 暗红熔岩光；正神 = 淡金色神光。
