# 01 立绘提示词（8 名无图鬼灵）

用途：生成与现有 14 名鬼灵同规格的「三视图」设定图，我会用现成的抠图管线切成正面 / 侧面 / 背面三张透明图接入游戏。

## 使用方法

1. **每次生成都把一张现有鬼灵的三视图当作「风格参考图」上传**（例如 天使-三视图.png），这样画风才能和已有角色一致。只参考画风，不参考角色。
2. 把下面的「通用段」原样放在最前面，再接该角色的「角色段」。
3. 画幅：横幅 16:9（或 3:2），分辨率越高越好，至少 2048 宽。
4. 交付给我时文件命名：`<id>-三视图.png`（id 见每个标题，如 `moonqueen-三视图.png`）。

> 说明：小说里对这 8 位几乎没有外貌描写，只有身份与能力。下面每条先列「原著依据」，其余外形是我按身份、技能和其它鬼灵的类型补全的设计，你可以随意改发色、服饰等细节。
> 现有 14 名鬼灵的实图我还没看到，「通用段」里的画风描述是按"漫画卡面 + 三视图"推定的；如与实际不符，以你上传的风格参考图为准。

## 通用段（每条都加）

```
二次元国风漫画角色设定图，三视图：同一名女性角色的正面、侧面、背面全身站姿，从左到右并排，三个视角等高、头身比完全一致、服饰发型完全一致，双臂自然下垂略微张开，完整露出头顶到脚底。纯白背景，无文字、无标注、无水印、无边框、无地面阴影、无额外道具悬浮遮挡身体。线条干净利落，赛璐璐上色加柔和渐变，五官精致，服饰纹样清晰可辨。整体色调偏冷、低饱和，带幽冥诡异的气质，但不血腥、不恐怖、不暴露。高清，细节丰富。
```

反向提示词（工具支持时填写）：

```
文字, 水印, 签名, 边框, 多个不同角色, 肢体残缺, 多余手指, 三个视角服装不一致, 复杂背景, 写实照片, 3D渲染, Q版, 血腥, 裸露
```

## 1. 月阙女王 `moonqueen`

- 原著依据：即「凤袍女鬼 / 凤袍女王」，沙漠死亡之海中月阙古城的古代女王，古城被鬼道人所灭；身穿凤袍，带女王威仪。
- 技能：火凤燎原 → 火焰规律（全体火焰伤害）、女王领域（压制全场敌人）。
- 类型：恶灵。主色：朱红、鎏金、焦黑。

```
角色：古代西域沙漠王国的亡国女王，外表约二十五岁，身材高挑，站姿笔直，下巴微抬，神情冷傲威严。乌黑长发高高盘成古式发髻，戴鎏金凤冠，凤冠两侧垂下细长金色流苏与红玛瑙珠。瞳色为熔金带赤红，眼尾一抹朱红眼妆，肤色苍白。身穿层叠的朱红色凤袍，外披广袖长袍与曳地长裙摆，胸前与背后用金线绣一只展翅的火凤凰，腰束镶绿松石的宽金腰带，颈戴多层黄金项圈，双腕金钏。凤袍的下摆与袖口边缘呈焦黑色，正在化作细小的金红色余烬向上飘散，仿佛永远在燃烧。背后隐约有几根由火焰构成的凤凰尾羽。背面视角要完整展示凤袍背后的火凤刺绣与曳地裙摆。
```

## 2. 薇拉 `weila`

- 原著依据：雪国三姐妹里的小妹，为了某件事把自己变成「咒灵」，因此一度丧失自我；能力是时间（时间之茧、时间回溯、吞掉别人的时间）。
- 技能：时间回退（记录友军状态并复活）、时间删除（让目标退场 4 回合）。
- 类型：规律鬼。主色：雪白、冰蓝、暗紫咒纹、旧黄铜。

```
角色：来自北方雪国的少女咒灵，外表约十六岁，身形纤细娇小，神情空茫恍惚，像刚从很长的梦里醒来。铂金色微卷长发及腰，头顶别一枚旧黄铜齿轮发饰，发梢渐变为半透明的冰蓝色。瞳色冰蓝，瞳孔里是一圈细小的钟表刻度。皮肤极白，左侧脖颈到左手手背爬着暗紫色的荆棘状咒纹。身穿雪国风格的白色与灰蓝色冬季长裙，立领与袖口镶白色毛边，裙摆有北欧风格的深蓝刺绣，外披一件短斗篷，脚穿系带短靴。腰间挂着一只表盖碎裂、指针停住的旧黄铜怀表，表链垂到膝盖。右手手腕缠着几圈发着微光的白色丝线，像没织完的茧。裙摆下缘有细沙状的光粒向上倒流。
```

## 3. 云梦女神 `yunmeng`

- 原著依据：云梦泽的「长公主」，身穿华美裙装，云梦泽里有她的神像；与凝蝶渊源很深。
- 技能：云梦泽（全体友军攻击与生命大幅提升，持续 7 回合）。
- 类型：善灵。主色：湖青、月白、淡金。

```
角色：古代楚地大泽的长公主，死后被供奉为水泽女神，外表约二十二岁，气质端庄温柔、带一点悲悯。墨黑长发垂至膝弯，上半部分挽成楚式垂髻，插银质莲花步摇与水滴形发簪。瞳色为清澈的湖青色，眉心一点淡金色水纹花钿。身穿层层叠叠的楚风曲裾深衣与华美长裙，颜色由月白过渡到湖青，衣缘绣淡金色云纹、莲纹与芦苇纹，细腰束宽腰封并垂下玉组佩，肩上披着极长的半透明披帛，像雾一样浮在身体两侧。裙摆最下端不是布料，而是逐渐化作薄雾与一圈圈水波纹。赤足，脚踝系银铃。头后有一轮极淡的水色光晕。
```

## 4. 囡囡 `nannan`

- 原著依据：小女孩，是「不一样的禁忌」，不能在外面待太久；她的头发能限制规律能力；与寂照庵有关。
- 技能：绝望（一次性，把敌方全体的生命和攻击都压成 100）。
- 类型：禁忌。主色：褪色的旧红、灰白、墨黑。
- 注意：要"诡异但不吓人"，不要血、不要伤口、不要狰狞表情。

```
角色：六七岁的小女孩模样的禁忌存在，个子很矮，约三头半身，安静地站着，没有任何表情，不哭不笑。乌黑的直发极长，一直垂到脚踝，齐刘海遮住一半眼睛；眼睛很大，瞳孔纯黑、没有高光。皮肤是没有血色的瓷白。身穿一件洗得发白褪色的旧式红色盘扣小棉袄和深灰色棉裤，脚穿黑色老布鞋，左手手腕系一根红绳。右手抱着一只打着补丁、纽扣眼睛掉了一颗的旧布娃娃。她脚边一圈的颜色像被抽走了一样变成灰白，并有几道细细的、像瓷器开片一样的裂纹向外延伸。背面视角几乎只能看到那一头垂到脚踝的黑发。整体可爱而令人不安，但不血腥、不恐怖。
```

## 5. 曦仪 `xiyi`

- 原著依据：手持「鬼帝权杖」，出手时一重重空间飞速降临。
- 技能：空间规律（让一个敌人无法攻击玩家）、鬼主权杖（一次性，秒杀一个圣灵三阶以下的鬼灵）。
- 类型：恶灵。主色：玄黑、深靛、幽绿、银。
- 与游戏内演出保持一致：权杖顶端是一颗幽绿色宝珠。

```
角色：执掌空间的鬼中帝女，外表约二十四岁，身材修长，气场凌厉，眼神居高临下。紫黑色长直发垂至大腿，发尾像被切碎的镜片一样呈现错位的几何断面，头戴一顶小巧的黑金帝冠。瞳色幽紫，瞳孔是一个菱形。身穿玄黑与深靛蓝相间的帝王制式长裙，高开衩不对称裙摆，衣身用银线绣星宿与层叠的方形回纹，单侧肩甲为黑金兽首，长手套，高跟长靴。右手竖握一柄比她还高的鬼帝权杖：杖身漆黑、缠银色龙纹，顶端由青铜鬼爪托着一颗发着幽绿色冷光的宝珠。她周身漂浮着几片薄如镜面的空间碎片，碎片里映出的是不同角度的她自己（碎片不要遮挡身体主体）。
```

## 6. 孟婆 `mengpo`

- 原著依据：主持着「小地府」，仍维持着一定的生灵轮回；与夜霜一起夺回地府。
- 技能：轮回（复活全部阵亡鬼灵）、地府降临（每回合额外恢复鬼气）。
- 类型：正神。主色：黛青、米白、彼岸花红、淡金。
- 设计取向：不是老妪，而是容貌年轻、气质却很古老的女子（与其它鬼灵的年龄段一致）。

```
角色：奈何桥边执掌轮回的女神，容貌是二十七八岁的温婉女子，眼神却像看过无数世人，平静而略带哀怜。银白色长发在脑后低低挽成一个松髻，插一根乌木簪，鬓边垂下两缕。瞳色为淡金色。身穿素雅的黛青色与米白色交领襦裙，外罩一件半旧的深色对襟长褙子，腰间系粗布围裙式的蔽膝，裙摆下缘绣着一圈盛开的红色彼岸花。双手捧着一只青瓷汤碗，碗中汤色清浅、升起一缕会自己打旋的白色雾气；腰侧挂一只木长柄汤勺和一盏熄着的小纸灯笼。脑后有一个极淡的金色六道轮回光环（细线构成的轮盘），脚边有几瓣飘落的彼岸花瓣。
```

## 7. 太阴星君 `taiyin`

- 原著依据：无外貌描写；东方的月神。
- 技能：太阴之力（每场一次，本回合额外获得 6 点鬼气）。
- 类型：正神。主色：月白、银、淡蓝。
- 与游戏内演出保持一致：带环形山的满月、云海。

```
角色：东方神话中掌管月亮的太阴星君，外表约二十岁，清冷出尘，神情淡漠疏离，几乎没有情绪。银白色长发如瀑垂至脚踝，头顶挽飞仙髻，戴一枚银质新月冠，额心有一枚淡蓝色月牙印记。瞳色为浅银灰。身穿月白色与极淡的冰蓝色广袖流仙裙，层层薄纱，衣缘用银线绣星斗、桂枝与云纹，腰间垂一枚玉兔形玉佩，臂间挽着长长的半透明披帛向后飘起。左手托着一面圆形的月轮宝镜，镜面像满月一样有淡淡的环形山纹理并发出冷光；右手拈一小枝带花的桂枝。脑后悬着一轮细银线勾出的满月光环。整个人像自带一层冷白的月辉。
```

## 8. 阿尔忒弥斯 `artemis`

- 原著依据：西方的月亮女神，同时是狩猎之神，武器是弓箭。
- 技能：复仇（受伤时 50% 概率反击，造成 200% 伤害）。
- 类型：正神。主色：银白、墨绿、淡金。
- 要与太阴星君拉开区别：太阴是东方、静、长裙；她是西方、动、短装猎装。

```
角色：古希腊的狩猎与月亮女神，外表约十九岁，身材矫健修长，有运动感，神情警觉锐利，像随时会放箭的猎手。淡金色长发编成一根高马尾长辫，额前戴一枚银质新月头冠，耳侧插一小段银色鹿角形发饰。瞳色为灰绿色。身穿及膝的白色希腊式短希顿裙，外覆银色轻甲：单肩护甲、胸甲、护腕和护胫，腰束皮质腰带，肩披一件墨绿色短披风，脚穿绑带皮凉鞋。背后斜背一只装满银羽箭的箭筒，左手握一张弯月形的银色长弓，弓身带月相浮雕。小腿和手臂上有几道旧的浅色伤痕（体现"复仇"）。背面视角要清楚展示箭筒、披风与长辫。
```
