# 04 技能视频提示词（22 名鬼灵全部技能 + 3 个御鬼者技能，共 73 条）

## 使用方法

1. **用「图生视频 / 角色参考」模式**：把该鬼灵的新卡面（文档 02）或三视图正面作为首帧或角色参考上传，再贴提示词。这样视频里的人和卡牌上是同一个人。
2. 「通用段」原样放最前面，再接该技能的那一段。
3. 规格：**横幅 16:9，1080p，mp4**；时长按每条标注（3–6 秒）；声音有没有都行，音效我在游戏里另配。
4. 文件命名用每条标题里的编号，如 `tong_1.mp4`、`xuan_2.mp4`。
5. 带「升级」说明的技能（如 鬼火 / 鬼火+）：先只做基础版一条就够用；想区分的话，按「升级」那句改一下再生成一条，文件名加 `p`（如 `xuan_2p.mp4`，再高一级 `pp`）。
6. 画面里的"敌人"统一是**黑雾构成的人影、没有五官、只有一双暗红色的眼睛**，和游戏里的对手一致。
7. 提示词是中文，适用可灵、即梦、Vidu、海螺等；如果你用的是只吃英文的工具（Sora、Veo、Runway），告诉我，我出一份英文版。

接入方式：我会把视频作为技能演出的全屏画面播放（1–2 级技能在斜切画幅里播，3–4 级全屏），可跳过。被动技能触发很频繁，每场战斗只在第一次触发时播视频，之后用短闪光。

## 通用段（每条都加）

```
电影感的东方暗黑幻想动画短片，半写实厚涂质感的二次元角色，角色外形、发型、服饰严格依照参考图且全程保持一致。整体色调限定在靛蓝、朱砂红、骨白、烛光暖金，暗部很深，发光的特效是画面最亮的部分，有体积光和飞散的粒子。一个连续镜头，不切镜；动作干净有力，先蓄势后爆发；最后半秒停在最有张力的姿势上。画面无文字、无字幕、无水印、无界面元素。不血腥、不暴露。
```

反向提示词（工具支持时填写）：

```
文字, 字幕, 水印, logo, 画面闪烁, 人物变形, 脸部崩坏, 多余肢体, 切镜, 多个主角, 真人实拍, 血腥
```
