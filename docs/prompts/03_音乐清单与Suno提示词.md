# 03 音乐清单与 Suno 提示词（共 22 首）

## 使用方法

1. Suno 里选 **Custom（自定义）模式**，打开 **Instrumental（纯音乐）**；下面的英文整段贴进 **Style of Music / Styles** 栏，Title 填文件名即可。只有第 22 首有歌词。
2. 提示词用英文写是因为 Suno 对英文风格词识别更稳，中文括号里是给你看的说明，不用贴。
3. 每首生成 2 个版本，挑一个；长度不用卡得很准，够「建议时长」就行。**不需要你做循环处理**，首尾衔接我在游戏里用交叉淡化完成。
4. 交付：mp3 或 wav 都可以，文件名按表里的「文件名」，如 `battle_1.mp3`。
5. 如果某首出来有人声哼唱，在 Styles 末尾加 `no vocals, no choir` 重生成（第 13、14、15、17 首故意要无词合唱，不用加）。

整体音乐方向：**中国民乐（古筝、琵琶、二胡、箫、埙、编钟、大鼓）+ 暗黑氛围电子 + 弦乐**，冷、空、克制，和游戏里"烛光牌桌、写实诡异"的画面一致。全套的调性尽量靠近 D 小调 / A 小调，方便曲目之间切换。
